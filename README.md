
# Flask CRUD Project 🐍

> Simple backend system built with Python + Flask + SQLite — learning by doing!

## 📌 About
This is my first full CRUD application. I built it step-by-step while learning:
- Python logic, functions and variables
- Flask framework for web routes
- SQLite database integration
- Bootstrap for clean interface

## ✨ Features
- ✅ Home page with programming basics explanation
- ✅ Products listing
- ✅ Create new items
- ✅ Read / display data from database
- ✅ Update existing records
- ✅ Delete items
- ✅ Responsive design with Bootstrap 5

## 🛠️ Technologies
| Tech | Description |
|---|---|
| Python 3 | Core language |
| Flask | Web framework |
| SQLite | Database |
| Bootstrap 5 | Styling & layout |

# Clone this project
